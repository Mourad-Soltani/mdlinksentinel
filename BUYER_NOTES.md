# Buyer notes for MDLinkSentinel
# Built by Mourad.Soltani

What you get:
- Single-file CLI `mdlinksentinel.py`
- Unit tests that pass
- MIT license
- README with usage

How to run:
1. Python 3.10+
2. pip install -r requirements.txt
3. python mdlinksentinel.py <path>

Requirements: internet for live checks, httpx.

Perfect for documentation maintainers and solo developers who want a lightweight broken-link scanner without heavy dependencies.
